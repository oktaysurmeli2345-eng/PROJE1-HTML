# Web Teknolojileri Projesi - Kişisel Web Sitesi

Selamlar, bu repo Sakarya Üniversitesi Bilgisayar Mühendisliği bölümünde aldığım Web Teknolojileri dersinin proje ödevi için oluşturuldu. 

Projeyi tamamen verilen şartnameye uygun olarak, kişisel bilgilerimin, ilgi alanlarımın ve şehrimin tanıtıldığı dinamik bir yapıda hazırladım.

## Projede Neler Var?

* **HTML5 & CSS:** Semantic etiketler (header, section, article vb.) kullanarak responsive bir tasarım çıkardım. Stillerin hepsini harici bir CSS dosyasında topladım.
* **JavaScript & Vue.js:** İletişim sayfasındaki form kontrollerini (boş alan, email ve telefon formatı vb.) hem saf JavaScript hem de Vue.js kullanarak iki ayrı butonda doğrulattım.
* **PHP:** Login sayfasında öğrenci numarası ve mail ile basit bir kimlik doğrulaması yapılıyor. İletişim formundan post edilen verileri de yine PHP ile yakalayıp ekrana yazdırıyorum.
* **API Entegrasyonu:** İlgi alanlarım sayfasında OMDb API kullanarak sevdiğim filmlerin verilerini dışarıdan çekerek listeledim.
